Zero Point Logic Studio

A Windows app for browsing, fixing and exporting pixel-art sprite libraries, with exports for Godot, Unity, GameMaker, RPG Maker, TexturePacker/Phaser and Aseprite. It ships with no art: you bring your own sprites.

Zero Point Logic Studio on itch.io · all releases

zpl-kernel

A small x86-64 research kernel in Rust that runs every state-changing request past a policy gate before carrying it out. It runs in QEMU; real-hardware support is early, and the README says exactly where it has been tested.

zpl-kernel on GitHub (GPL-3.0)

prodcheck

Finds production bugs that ship green: swallowed webhooks, bypassable rate limits, unsafe credential defaults.

Discontinued

The ZPL Engine API and its SDK, CLI and MCP server were discontinued in October 2026. The service is offline, the npm packages are marked deprecated and their repositories are archived. Directory listings that still describe them are out of date.
